# what/: knowledge

- `context/`: research, analysis, compendia and working links. Each doc cites its sources.
- `context/research/`: numbered research tracks (`0N_name.md`) plus an index `README.md`.
- `context/archive/`: superseded docs, kept with `superseded_by` and a banner naming the replacement.
- `decisions/`: ADRs (`adr_NNN_slug.md`) with Context / Decision / Consequences / Ratification. Only the owner ratifies; see [decision rights](../who/governance/decision_rights.md).
