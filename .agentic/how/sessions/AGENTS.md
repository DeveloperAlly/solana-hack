# sessions/

This folder holds records of individual working sessions (what was attempted, what changed, what was handed off), one file per session, when session logging is turned on. It is a Starter-conformance stub and is not used during the hackathon: the end-of-session update to [STATE.md](../../../STATE.md) is the only required session record.
