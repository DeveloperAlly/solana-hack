# Waterlily

**Waterlily: build your brand, run it, prove it.**

Waterlily is a brand superhub: it builds a brand from scratch through a guided interview, then writes, plans and schedules content in that brand's voice with a person approving everything. It runs the brand day to day, from campaigns and engagement to paying curated ambassadors in USDC per verified post. On Solana, a proof layer records what is official (the brand's identity, accounts, content, claims with evidence and AI personas) so anyone can check it.
